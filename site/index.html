About

Tell {{ page.appname }} what TLS versions and associated ciphers you want to enable and it will generate a script that configures a {{ page.distro }} {{ page.distro_version }} server exactly as you specify. It autoconfigures Apache, grabs certificates from LetsEncrypt and applies your TLS settings.

This project is unfinished. The implementation of TLS 1.3 cipher selection in this project is currently broken. Do not use TLS 1.3 for testing with this project.

You can find the code repository for this project at {{ page.repo }}

Cipher Settings

Below are listed the ciphers available to each version of the TLS protocol. If you enable one cipher under a particular TLS protocol, that protocol will be enabled on your server, if no ciphers are selected, that protocol will be disabled.

You will notice that some ciphers exist in more than one list; that is because some ciphers are available for use in several versions of the TLS protocol. If you select a cipher that is listed under TLS 1.2, but which is also available in TLS 1.1/1.0, it will not automatically enable protocols TLS1.1/1.0, unless you select the same cipher under those protocols, or have otherwise enabled other ciphers on those protocols.

If you're unfamiliar of how the TLS protocols work with ciphers, I strongly recommend you run tests against your server after you deploy it, using either Qualys' SSLLabs tool or by using the ssl-enum-ciphers script bundled with the nmap network scanning tool.
